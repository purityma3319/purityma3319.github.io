## 🎯 What Is ApexRAR?

ApexRAR is a desktop application that opens and extracts RAR archive files. You do not need to know anything about file compression or command lines. This program gives you a simple window where you pick a RAR file and choose where to save its contents.

Think of it like a digital key for locked folders. RAR files pack many files into one smaller package. ApexRAR unlocks that package so you can use the files inside.

## ✨ Key Features

- **Open RAR files** - Works with RAR and RAR4 formats.
- **Extract all files** - Gets everything out of the archive at once.
- **Extract selected files** - Pick only the files you want.
- **Password support** - Opens password-protected RAR files.
- **Drag and drop** - Drag RAR files onto the window to start.
- **Progress bar** - Shows how much time remains.
- **Simple interface** - Three buttons. One window.

## 🎮 How to Use ApexRAR

### Open a RAR File

1. Click the "Open" button.
2. Browse to your RAR file.
3. Double-click it.

The program shows you what is inside.

### Extract Everything

1. Click "Extract All."
2. Choose a destination folder (or create a new one).
3. Click "OK."

All files come out of the archive into that folder.

### Extract Specific Files

1. Click a file inside the RAR archive to select it.
2. Hold the Ctrl key to select multiple files.
3. Click "Extract Selected."
4. Pick the destination folder.
5. Click "OK."

### Use Password-Protected Files

1. Open the RAR file as normal.
2. The program asks for a password.
3. Type the password.
4. Click "OK."

If the password is wrong, the program tells you.

## 🔧 Troubleshooting

**Problem:** The installer does not start.
**Solution:** Right-click the `.exe` file and choose "Run as administrator."

**Problem:** Windows gives a warning about unknown publisher.
**Solution:** Click "More info" then "Run anyway." This is normal for new software.

**Problem:** The program says "File is corrupted."
**Solution:** Download the file again. The download might have failed.

**Problem:** The program cannot open a RAR file.
**Solution:** Make sure the file ends in `.rar`. Some files end in `.zip` or `.7z`. ApexRAR only opens RAR files.

**Problem:** Extraction takes too long.
**Solution:** Large files take time. A 1 GB file might take 5 minutes. Be patient.

**Problem:** The program crashes or freezes.
**Solution:** Close it and reopen it. If the problem continues, restart your computer.

**Problem:** I deleted the files by accident.
**Solution:** Check your Recycle Bin. ApexRAR does not delete original archives during extraction.
